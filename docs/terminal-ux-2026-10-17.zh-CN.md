# 终端交互统一与 CommandCode 登录修复（2026-10-17 第二轮）

本轮按用户反馈处理三件事：终端操作逻辑不统一、CommandCode 提供商无法登录、改名后的遗留兼容。附带修复帧键性能热点，并把工具执行区改成卡片式（对齐 CommandCode 风格）。范围仍为 Terminal 与终端使用的 Core/插件。

## 一、操作逻辑统一（按键语义）

统一后的模型：Esc 只做"停止/返回"，草稿永不被误删；退出是显式动作；补全只属于 Tab。

| 场景 | 之前 | 现在 |
|---|---|---|
| 空输入 Ctrl+C | 静默无反应（无法退出） | 第一按提示"再按一次 Ctrl+C 退出"，2 秒内第二按退出；Ctrl+D 直接退出 |
| 空输入 Ctrl+D | 无处理 | 退出聊天 |
| 退出命令 | 不存在 | `/exit`、`/quit`；退出时打印会话保存位置与恢复命令 |
| 输入非空 Ctrl+C | 清空且清掉撤销栈 | 清空但保留 Ctrl+Z 恢复，并提示 |
| Esc（空闲） | 静默清空整段草稿且不可恢复 | 保留草稿，仅关闭选区/历史搜索并给出提示；清空用 Ctrl+U |
| Esc（任务运行中） | 双击（5 秒窗口）才取消，首按几乎无反馈 | 单击立即停止当前任务 |
| Esc（等待类操作） | 双击确认 | 单击取消 |
| Tab（空输入） | 静默切换只读规划模式（易误触） | 无动作；权限切换改为 Shift+Tab，侧栏同步标注 |
| Ctrl+X,Q / Ctrl+X,G | 隐藏 chord，2 秒内吞掉普通输入 | 移除；/queue、/timeline 命令保留 |
| Ctrl+E | 有执行块时打开详情，否则跳到行尾（含义不定） | 固定为 emacs 行尾；展开详情统一为 Ctrl+O（执行块/思考，与"还有 N 行 · Ctrl+O 展开"一致） |

其它交互修复：

- 聊天输入状态跨提示、面板持久保留（光标、撤销栈、历史搜索状态不再每次重建）。
- 管理面板（/model、/login、/plugins、F1 菜单、命令面板等）从"清屏模态"改为同帧覆盖层：不再闪屏，Esc 返回不再丢失外层状态；面板内支持输入过滤（命令面板、模型选择等）。
- 文本输入框（含密钥输入）改为覆盖层实现，Esc 语义与其它面板一致。
- `/timeline` 退出时恢复进入前的滚动位置；`/queue` 面板同帧渲染。
- 大段粘贴超过 32000 字符不再静默丢尾部：草稿内插入"[粘贴内容超过 32000 字符，已截断]"标记。
- 文案统一：运行中提示"Esc 停止"；帮助、侧栏、页脚全部改为 Ctrl+O 展开、Shift+Tab 规划、/exit 退出。

## 二、CommandCode 登录与额度

根因有两个：

1. 插件从未安装成功（本机数据目录里只有旧版 lanagent.* 插件），`/login commandcode` 自然报"登录提供商不存在"；而旧插件包（`lanagent-plugin.json` + 旧程序集引用）在新宿主下加载失败，错误信息也没有说明原因。
2. 旧流程要求先在环境变量里放密钥再重启进程，用户实际几乎无法完成登录。

修复：

- 新增可选接口 `IInteractiveAuthentication`（插件契约，默认不破坏现有插件）：宿主在 `/login` 里直接弹出密钥输入框。
- CommandCode 插件实现该接口：`/login commandcode` → 选择 CommandCode → 粘贴 `user_` 开头的 API Key → 验证（拉取模型目录）成功后经 TokenVault（DPAPI）加密保存 → 自动连接模型配置。环境变量方式仍兼容。
- 密钥清洗对齐官方 CLI：可整段粘贴 `Bearer user_xxx`、`token_user_xxx`（正则提取 `user_[A-Za-z0-9_-]+`），拒绝 `sk-` 前缀。
- 协议对齐 commandcode-proxy：模型目录 `?view=client`；`max_tokens` 未设置时默认 64000（修复了登录后 MaxTokens=0 会被夹成 1、模型只能输出一个 token 的问题）；HTTP 错误携带结构化状态码以进入引擎的重试分支。
- **额度显示**：模型页脚新增"CommandCode 额度 剩余 X（月付 · 购买 · 免费）"与"CommandCode 计划 · N 天后重置"，来自官方 `/alpha/billing/credits`、`/alpha/billing/subscriptions`、`/alpha/whoami?limits=1`（60 秒后台缓存，不阻塞渲染）；`/ext commandcode-status` 同步显示。失败时显示"未登录 / 当前授权无法读取 / 查询失败 HTTP xxx"，不虚构数值。
- `PluginHost` 对旧版插件包给出明确错误："这是旧版 LanAgent 插件包…请重新构建并安装新版插件包（/plugins import）"。

## 二·补：自带插件与提供商选择界面

- **CommandCode 作为自带插件**：终端构建把 `AllAgent.NET.CommandCode.dll` + 清单复制到输出目录 `builtin-plugins/AllAgent.NET.CommandCode/`；启动时 `PluginHost.InstallBuiltins` 在共享插件目录里安装一次（已安装过则保留用户版本，绝不覆盖），随后按正常插件流程加载。NuGet 工具包同样携带 `builtin-plugins/`。
- **提供商选择界面重写**：`/model`、`/providers edit`、添加提供商、`/login` 的列表统一"账号登录优先"：OAuth/账号类提供商（Codex、CommandCode 等）排在最前，API Key 类预设随后，均带 `· 账号登录 / · API Key` 标注；添加流程里选择账号提供商直接进入登录（含交互式密钥输入），登录成功后自动建立配置，不再要求用户理解"先 wizard 再 login"的顺序。
- **列表行为**：搜索/输入过滤后列表只显示匹配项（全屏覆盖层与内联选择器一致）；所有选择列表、审批选项、模型列表到顶/到底都不再循环滚动（`WrapAround` 移除、hint 选择与审批选择改为夹取）。

## 三、改名遗留兼容

- 旧共享目录（`%APPDATA%\LanAgent`）与新目录（`AllAgent.NET`）的复用逻辑已有回退；本轮确认插件/凭据沿用同一回退目录，不会读到空库。
- 旧插件目录的加载失败从泛化异常改为可读提示（见上）。
- 全量构建通过，未发现改名造成的编译级断裂；仅文档与历史称呼保留旧名。

## 四、性能

- `CodeExecutionBlock.Version`：从"每帧对全部执行块做 JSON 解析 + LINQ 排序"改为 250ms 节流 + 任务查询记忆化；Start/Complete/标记变化时强制失效。长会话打字的帧成本不再随执行块历史线性增长。
- `Draw()` 帧键：空闲时不再因秒数变化每秒强制全帧重建（仅活动行/详情视图动画参与）。
- 流式活动行只渲染尾部窗口（回答 6000 字符、思考 4000 字符），避免 50KB 级字符串每 50ms 全量复制与字素解析。

## 五、显示（CommandCode 风格）

- 工具执行改为**轻量行式徽标**：一行 = 彩色徽标（SHELL / READ / EDIT…）+ 加粗任务目标 + 内联状态（成功绿 / 失败红 / 运行中青，子代理取任务状态色）；正文树形缩进（"│ 输出行"），折叠提示只在末行——"…还有 N 行 [Ctrl+O 展开]"。
- 不再给每个工具画整块绿框、不再单独占一行显示"状态 · 成功"、不再每张卡重复"点击操作查看详情"；调度代码（"代码 › …"）从主信息流移除，仅在 Ctrl+O 详情中展示（对齐 Command Code：主视图只保留徽标行与结果预览）。
- 思考行前缀统一为"✳ 思考"，保留"（N 行）[Ctrl+O 展开]"提示；后台/子代理任务卡仍保留圆角框（Command Code 对后台任务同样用框）。
- 终端装饰色（输入框标题、命令高亮、加载行）全部改取主题色，浅色主题下不再出现低对比度的硬编码青色。
- 欢迎页补充退出提示。
