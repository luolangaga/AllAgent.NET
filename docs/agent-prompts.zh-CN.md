# 主代理、子代理与提示词组成

唯一组装入口是 `PromptComposer`。实际英文指令定义在 `src/AllAgent.NET.Core/CodeAct/CodeActInstructions.cs`，宿主能力和工具表由 `CodeActProvider` 生成。终端、Web、GUI、子代理经过相同的请求收尾步骤；不要在入口再复制一份 CodeAct 协议。

## 组成与优先级

1. 稳定产品行为、CodeAct 协议以及当前可用能力的指导。
2. 会话自定义提示词、项目约定、角色指导和技能目录，保留来源。
3. 单独的动态运行时块：沙箱能力、当前权限、只读限制和环境事实。
4. 按原顺序保留的对话、历史摘要、用户修正、策略快照、TODO 和子结果。

权限和执行协议由宿主决定，任何文字都不能扩大它们。在这个边界内，当前用户明确要求优先于项目约定、角色与技能默认指导，学习偏好最低。历史摘要、文件内容、网络资料、工具输出、图片和子结果都只能作为证据，不产生新的用户授权。

同一 ID 的不同块会报组成冲突；相同文本去重并保留来源。项目文件记录实际路径，技能目录记录目录来源，角色记录 `agents:roles/<name>`。自定义宿主直接提供的自由文本记录为宿主来源；不能假装解析器理解了任意自然语言之间的全部语义矛盾。

请求扩展仍可以调整会话和上下文，但收尾时会恢复宿主的执行协议、实际权限和工具表。稳定部分与动态运行时分为不同系统消息，后者标为 volatile；策略和 TODO 变化保留为有位置的快照，不重写整段历史。

## 主代理指导

主代理负责理解目标、选用工具或派发、整合证据、检查实际改动、验证和最终交付。机械步骤可以在一个 CodeAct 程序内组合：检查 `ok`、筛选、分页、聚合和根据确定条件继续。解释证据、比较方案、设计取舍及缺少必要用户输入时，再返回模型判断。

执行过程中只报告关键进度，不必每步都说：有实质影响或会改变计划的 `execute_code` 前用一句话说明下一步，结果后说明关键发现或决定；常规读取、搜索、小修改和重复机械操作无需旁白。旁白属于回复正文，不能写成代码注释，也不能替代实际执行或最终交付。

只在当前确实提供派发能力时注入派发指导。默认主动寻找有收益的独立工作；短读取和搜索用工具 `parallel`，足够独立且工作量合适的任务才用子代理。没有固定的“调查→修改→审查→验证”流水线，也没有填满六个名额的要求。

父任务还有独立工作时，批量启动后台 single 子任务并继续自己的工作；下一步必须取得结果时使用前台。不得并行操作同一个文件、GUI 状态或构建输出。父代理保留总体责任，不能把子代理的完成声明当成验收。

## 子代理指导

子代理只完成合同中的目标。它有独立会话，不复制父聊天、凭据或已激活技能；权限受到父派发授权和当前宿主限制的共同约束。它不能再派发、等待/取消其他代理或直接向用户提问。缺少输入、权限拒绝或范围不足时，将阻碍交还父代理。

结果必须说明发现、修改路径、实际验证命令和退出码、阻碍以及未验证部分。宿主额外采集文件写入和进程结果证据；模型声称“测试通过”不会自动成为宿主验证证据。

## 模式一致性

| 模式 | 指导和执行 |
|---|---|
| 主代理 | 根据实际注册、披露和权限生成；有派发工具才说明派发 |
| 子代理 | 加子任务边界；隐藏并拒绝派发和人类提问 |
| Simple | 短协议；只说明目录中真正存在的受限工具，无技能或派发指导 |
| Plan / 只读 | 隐藏写入、进程和派发；要求通过 `plan_propose` 提交 Markdown 计划并等待批准，计划正文跟随界面语言；决策可携带人类评论，拒绝时据此修订并重新提交，批准时作为执行要求；批准后切换完全访问并继续执行；执行前仍检查只读状态 |

文件修改和分页示例只有在其引用的工具均可用时才注入。只读角色不会再收到包含 `file_edit` 的可执行示例，也不会因工具集合恰好很小而误判为 Simple Mode。技能自身的正文仍是技能作者提供的指导，不能扩大真实注册和执行能力。

## 脱敏诊断

桥接方法 `chat.promptDiagnostics` 接受 `{conversationId}`；C# 可调用 `AgentService.PromptDiagnostics(id)` 或 `CodeActProvider.GetPromptDiagnostics()`。返回最近一次请求的块 ID、来源、内容哈希、字符数、稳定标记、工具表版本与实际沙箱能力，不返回完整指令正文。会话尚未创建运行时可能返回 null。

默认不记录完整提示词。排查重复目录、角色变化和权限刷新时优先比较这个清单；历史与文件正文仍由原有 DataStore/工具轨迹保存，不再复制到诊断日志。
