## 共享配置恢复修复

本次现场还发现并修复了一次配置丢失：

- 现象：共享配置在启动瞬间缺失时，`DataStore` 会用工作区清单（按设计不含模型配置）播种并立即写盘，导致 8 个模型配置被空数据覆盖；同目录空的 `allagent.json` 又会遮蔽旧版 `lanagent.json`。
- 修复：共享配置缺失时先短暂重试，再读取 `.bak` 恢复；工作区没有真实配置时不创建空共享文件；不覆盖仍然存在的备份；文件损坏时保留原文件并报错；没有共享清单时优先读取旧版 `lanagent.json`。
- 恢复：已从 `%USERPROFILE%\.lanagent\data\lanagent.json` 将 8 个模型配置合并回 `%APPDATA%\AllAgent.NET\allagent.json`，并用带 API Key 的 DeepSeek 配置完成真实连通性验证。
