# 终端交互与后台查询修复（2026-10-11）

本轮保持现有 CodeAct 架构，只修改终端和宿主行为。

后台任务默认不限制并发，不再共用固定两个执行槽，也取消了 32 个未完成任务的硬上限。未完成任务全部写入任务快照，历史完成记录最多保留 500 条。可通过 `--background-concurrency N` 自行启用并发限制，`0` 表示不限，正整数不再限制为最多 8。不限并发不意味着单条命令一定能利用所有 CPU；实际并行能力取决于命令本身和任务依赖，同一 Agent 会话与同一 CodeAct guest 的执行仍保持顺序。

## 已实现

- 自动加载用户目录下 `.agents/skills`、`.codex/skills`（含 `.system`）、`.claude/skills`、`.config/opencode/skills`。工作区技能优先；支持文件仍受包目录路径策略限制。目录列表缓存一秒，大型说明通过 `skill_read` 分页读取。
- 全局安装的 Junction／符号链接解析为实际技能包路径后加载，不再沿用工作区禁止链接的扫描规则；扫描取消前 200 项截断。支持文件读取仍限制在解析后的包目录内。真实用户目录验证发现 95 个启用的全局技能；18 个链接的目标已不存在，诊断明确报告缺失目标。
- `/` 提示列表中蓝色 `● 技能` 标记技能，绿色 `● 命令` 标记内置与扩展命令；标记在选中和未选中状态下保持来源颜色。
- 用户技能调用先解析用户参数中的文件／图片引用，再附加技能正文，不再把技能里的 npm 包名（例如 `@openai/codex`、`@chenglou/pretext`）当成本地引用。用户显式引用缺失文件仍报错，图片附件正常传递。
- 思考与调度代码显示一行摘要和 `(N 行)`；完整代码和调用结果保留在详情。
- 连续拖选事件合并到最新坐标，保留按下、释放与键盘事件顺序。点击消息输出区后，上下键滚动；点击输入区恢复输入操作。
- 查询已有任务显示为单行“查询已有任务”，查询区标题为“任务查询”，不再重复绘制启动命令卡片。查询失败保留错误。
- `shell_status` 默认等待最多 60 秒，完成即返回；宿主等待任务完成，不再每 100 毫秒读取任务状态。等待期间不调用模型；取消等待不取消后台进程。
- 未完成的查询结果省略累积输出和步骤历史；完整实时输出留在宿主界面，任务完成后返回输出。模型指引要求普通有限命令优先前台执行，后台任务先做独立工作、需要结果时再等待，避免短间隔查询与无变化重跑测试。
- 每个 Hyperlight worker 配置初始 1 个、最多 2 个 surrogate。旧进程仍使用启动时配置，需要正常退出后重启终端。

## 参考依据与范围

[Claude Code 官方文档](https://code.claude.com/docs/en/sub-agents)说明后台子代理通过完成通知返回结果。[Gemini CLI Shell 源码](https://github.com/google-gemini/gemini-cli/blob/main/packages/core/src/tools/shell.ts)使用输出事件更新展示，并等待执行结果。参考这些机制分离宿主刷新和模型调用，没有迁移或重构其整个实现。

本轮 Shell 等待仍有 60 秒上限：超过上限后模型可能再次请求等待。现有子代理完成通知已存在，但 Shell 的完整主动完成通知尚未接入，不能声称消除了所有查询或计算了实际 Token 节省量。数据存储仍使用原有全量原子保存，磁盘写入问题尚未完成优化。

## 子代理界面、取消确认与运行中重试

- 运行任务时第一次 Esc 显示取消确认，5 秒内第二次 Esc 才停止任务；其他输入会解除确认。弹窗关闭、拒绝授权／跳过问题仍沿用单次 Esc。Ctrl+C 继续作为立即中断快捷键。
- 子代理卡片详情与 `/tasks show ID` 展示消息、图片、思考摘要、代码执行卡片与实时输出，使用主消息已有的渲染组件。实时事件保留在内存中，显示刷新不产生额外模型调用或逐 Token 磁盘保存。
- 普通历史列表、恢复会话选择器和侧栏近期会话只显示主会话。子代理记录继续隶属于父会话，通过 `/child`、任务卡片与任务详情访问，保留恢复所需的数据。
- 运行过程中的 SSL／TLS 连接错误文本也纳入模型请求重试。临时连接故障、HTTP 429 和 5xx 最多重试 5 次，退避为 2、4、8、16、30 秒；取消立即结束等待。重试保留已完成工具结果，丢弃中断模型响应的部分文字和未执行调用，界面显示重试进度。
