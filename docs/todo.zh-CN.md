# TODO 执行清单

每个会话独立保存 TODO；主代理和子代理不会互相覆盖清单。清单随会话的不可变版本持久化，重启后可继续查看。中断和失败不会自动将未完成项标成完成。

多步骤任务会通过提示词引导代理先创建清单、推进时更新进度。是否创建清单由模型判断；单步问题无需创建。状态为 `pending`（待处理）、`in_progress`（进行中）、`completed`（已完成）；并行推进的多项可以同时处于进行中。

终端命令：

- `/todo`：查看当前清单与序号。
- `/todo add 内容`：新增待办。
- `/todo start 序号`：开始该项，其他进行中项保持不变。
- `/todo done 序号`：完成该项。
- `/todo pending 序号`：重新标为待处理。
- `/todo remove 序号`：删除该项。
- `/todo clear`：清空清单。

桌面聊天中的 TODO 面板显示实时进度，支持添加、删除；状态只读展示，由代理的 `todo_write` 与终端 `/todo start|done|pending` 推进。生成期间暂停手动编辑。终端全屏界面在清单非空时于侧栏右下角显示完成数、进度条以及进行中/待处理项，`todo_write` 和 `/todo` 更新后立即刷新。

CodeAct 中使用 `call_tool("todo_read")` 读取，使用 `call_tool("todo_write", todos=[{"id":"1","content":"实现功能","status":"in_progress"}])` 替换完整清单。保留稳定 ID 和未完成项，空数组清空。工具只操作当前执行会话，不接受目标会话 ID；更新清单只记录进度，不会执行任务，也不授予额外权限。

限制：最多 100 项，ID 1–64 字符且唯一，内容 1–300 字符。非法更新会被整体拒绝。TODO 属于当前会话状态，撤回历史消息不会自动回滚清单。
